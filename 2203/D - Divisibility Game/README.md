They have an array $$$a$$$ of $$$n$$$ elements and an array $$$b$$$ of $$$m$$$ elements.</p><p>The players take turns. Alice goes first. </li><li> the sum of $$$m$$$ over all test cases does not exceed $$$10^6$$$. </li></ul></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, print one word:</p><ul> <li> <span class="tex-font-style-tt">Alice</span> if Alice wins;
